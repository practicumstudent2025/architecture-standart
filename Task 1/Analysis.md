# Анализ проблем и рекомендации для цифровой трансформации банка "Стандарт"

## Ключевые проблемы текущего IT-ландшафта

### 1. Проблемы интеграции
- **Прямая интеграция интернет-банка с АБС**: Интернет-банк напрямую обращается к базе данных АБС, что создает риски безопасности и сложности в поддержке
- **Отсутствие API-слоя**: Нет единого интерфейса для взаимодействия между системами
- **Ручные процессы**: Много ручных операций с Excel-файлами для расчета ставок
- **Почтовые коммуникации**: Медленный обмен информацией между отделами через email

### 2. Проблемы архитектуры
- **Монолитная архитектура интернет-банка**: Сложно масштабировать и развивать
- **Устаревшие технологии**: ASP.NET MVC 4.5, Delphi, устаревшие версии фреймворков
- **Отсутствие микросервисной архитектуры**: Все системы тесно связаны
- **Разделение доступа к данным**: Сотрудники депозитов и кредитов не имеют доступа к данным друг друга

### 3. Проблемы процессов
- **Длительное время обработки**: 20 минут - 1 час для открытия депозита
- **Участие бэк-офиса**: Сотрудники бэк-офиса вовлечены в ручные процессы
- **Отсутствие автоматизации**: Ручные расчеты ставок и согласования
- **Сложный документооборот**: Бумажные документы и их загрузка в АБС

## Детальный анализ текущего процесса открытия депозита

### Этапы процесса:
1. **Подача заявки**: Клиент может подать заявку только в отделении или позвонить в кол-центр
2. **Расчет ставок**: Сотрудники отдела кредитования вручную рассчитывают ставки в Excel на основе данных ЦБ
3. **Обработка заявок**: При звонке в кол-центр создается обращение, которое передается в АБС
4. **Предварительная обработка**: Бэк-офис обрабатывает заявки заранее и определяет ставки
5. **Уведомление клиента**: АБС отправляет СМС с предложением ставки
6. **Специальные ставки**: При необходимости - дополнительная переписка между отделами
7. **Создание депозита**: Фронт-офис создает депозит в АБС и выдает документы
8. **Документооборот**: Подписанные документы загружаются в АБС

### Проблемные зоны процесса:
- **Ручные расчеты в Excel**: Неэффективный и подверженный ошибкам процесс
- **Почтовые коммуникации**: Медленный обмен информацией между отделами
- **Разделение доступа**: Сложности с безопасностью и доступом к данным
- **Бумажный документооборот**: Необходимость физического присутствия клиента

## Рекомендации по цифровой трансформации

### 1. Краткосрочные решения (6 месяцев)

#### Создание MVP для онлайн-депозитов
- **Разработка API-шлюза** между интернет-банком и АБС
- **Автоматизация расчета ставок** - перенос логики из Excel в систему
- **Создание веб-формы** для подачи заявок на депозиты
- **Интеграция с системой кол-центра** для обработки заявок
- **Автоматизация уведомлений** - замена СМС на push-уведомления

#### Технические улучшения
- **Обновление интернет-банка** до современных версий .NET
- **Создание REST API** для взаимодействия между системами
- **Внедрение системы логирования** для отслеживания процессов
- **Интеграция с внешними источниками данных** для автоматического расчета ставок

### 2. Долгосрочные решения (1 год)

#### Полная автоматизация процессов
- **Исключение участия бэк-офиса** в процессе открытия депозитов
- **Автоматический расчет ставок** на основе рыночных данных
- **Цифровое подписание документов** через интернет-банк
- **Интеграция с внешними системами** для получения рыночных данных
- **Устранение почтовых коммуникаций** - замена на автоматические процессы

#### Архитектурные изменения
- **Переход на микросервисную архитектуру**
- **Внедрение контейнеризации** (Docker, Kubernetes)
- **Создание API Gateway** для централизованного управления API
- **Внедрение системы мониторинга** и алертинга
- **Создание единой системы управления доступом** с соблюдением требований безопасности

### 3. Стратегические направления

#### Развитие цифровых каналов
- **Мобильное приложение** для iOS и Android
- **Чат-боты** для автоматизации простых операций
- **Интеграция с мессенджерами** для уведомлений
- **Персонализация** предложений на основе данных клиента

#### Улучшение клиентского опыта
- **Единый кабинет** для всех продуктов банка
- **Упрощение процессов** - сокращение количества шагов
- **Прозрачность** - клиент видит статус своей заявки
- **Мультиканальность** - возможность начать процесс в одном канале, завершить в другом

- Внедрение цифрового подписания документов
- Устранение почтовых коммуникаций
- Масштабирование на все продукты
