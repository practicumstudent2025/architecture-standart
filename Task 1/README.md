# Задание 1: Карта IT-ландшафта и схема интеграции приложений

## Описание проекта
Цифровая трансформация банка «Стандарт» - расширение функционала онлайн-каналов для привлечения клиентов и развития бизнеса.

## Цели бизнеса
1. **Промежуточное состояние (через 6 месяцев)**: Клиент может открыть депозит или накопительный счёт в интернет-банке. В MVP бэк-офис может обрабатывать заявки по старому процессу.

2. **Финальное состояние (через год)**: Клиент открывает депозит или накопительный счёт в интернет-банке автоматически без участия сотрудников бэк-офиса.

## Текущие проблемы
- Сложный процесс открытия депозитов с участием бэк-офиса
- Ручные расчеты ставок в Excel
- Отсутствие автоматизации процессов
- Длительное время обработки заявок (20 минут - 1 час)

- `Integration-Diagram.drawio` - Схема интеграции приложений

## Организационная структура банка "Стандарт"

### Основные направления:
1. **Управление обслуживанием в сети отделений** (500 человек, 50 отделений)
2. **Управление IT** (40 человек: 10 внутренних + 10 подрядчик + 20 АБС)
3. **Управление обслуживанием депозитных продуктов** (50 человек)
4. **Управление обслуживанием кредитных продуктов** (50 человек)
5. **Кол-центр банка** (200 операторов)
6. **Партнёрский кол-центр** (100 человек)
7. **Команда цифровой трансформации розничного бизнеса** (10 человек)

## IT-системы:
- **Интернет-банк**: ASP.NET MVC 4.5, .NET Framework 4.5, MS SQL
- **АБС**: Delphi клиент, Oracle СУБД, PL-SQL
- **Система кол-центра**: React.js, Java Spring Boot, PostgreSQL
- **Сайт**: PHP, React.js
- **СМС-шлюз**: внешний телеком-оператор
