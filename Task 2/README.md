# Задание 2: FURPS+ таблица требований

## Описание проекта
Цифровая трансформация депозитного направления банка "Стандарт" - создание MVP для онлайн-открытия депозитов.

## Цели проекта
- Позволить клиентам подавать заявки на депозиты через сайт и интернет-банк
- Автоматизировать процесс обработки заявок
- Улучшить клиентский опыт
- Сократить операционные издержки

## Основные требования MVP

### Функциональные требования:
1. **Сайт**: Просмотр депозитов, подача заявок новыми клиентами
2. **Интернет-банк**: Персонализированные ставки, подача заявок существующими клиентами
3. **Кол-центр**: Обработка заявок с сайта, предложение особых условий
4. **Бэк-офис**: Подтверждение условий депозита в АБС
5. **Уведомления**: СМС-коды для подтверждения, уведомления о статусе

### Критичные ограничения:
- **Перегрузка АБС**: Избежание прямой интеграции интернет-банка с АБС
- **Безопасность**: Шифрование трафика для защиты чувствительных данных
- **Доступность**: 99.9% доступность, работа 24/7
- **Производительность**: Отклик в миллисекундах

## Архитектурные решения

### Ключевые принципы:
1. **Использование существующих технологий** - MS SQL, Oracle, текущие платформы
2. **Избежание прямой интеграции с АБС** - создание API-шлюза
3. **Горизонтальное масштабирование** - распределение нагрузки
4. **Резервирование ЦОД** - обеспечение отказоустойчивости
5. **Переиспользование компонентов** - существующий СМС-функционал

### Технологические ограничения:
- Текущая версия платформы интернет-банка несовместима с Kafka
- АБС может масштабироваться только вертикально
- Необходимость совместимости с существующими системами
