Описание диаграммы

Диаграмма контейнеров показывает детальную архитектуру системы открытия депозитов онлайн с разделением на слои:

Presentation Layer (Слой представления):

  • Веб-сайт банка - публичный доступ к информации о депозитах и подача заявок
  • Интернет-банк - персонализированный доступ для авторизованных клиентов

Integration Layer (Слой интеграции):

  • API Gateway - централизованная точка входа с аутентификацией, авторизацией и кэшированием
  • Система очередей - асинхронная обработка заявок и уведомлений

Business Logic Layer (Слой бизнес-логики):

  • Сервис депозитов - основная бизнес-логика обработки заявок
  • Сервис ставок - управление ставками и условиями депозитов

Data Layer (Слой данных):

  • База данных - хранение заявок, конфигурации и логов
  • Система кэширования - быстрый доступ к справочным данным
  • База данных АБС - основная банковская система (ограниченный доступ)
  • API АБС - интерфейс для работы с банковскими операциями

External Systems (Внешние системы):

  • Кол-центр - система обработки звонков и заявок
  • СМС-шлюз - отправка SMS уведомлений
  • Email-сервис - отправка email уведомлений
  • Система мониторинга - контроль производительности и доступности

Ключевые особенности архитектуры:

  • API Gateway защищает от перегрузки АБС и обеспечивает централизованную точку входа
  • Асинхронная обработка через систему очередей снижает нагрузку на критические системы
  • Кэширование ускоряет загрузку справочных данных
  • Ограниченный доступ к АБС предотвращает перегрузку основной банковской системы
  • Мониторинг обеспечивает контроль производительности всех компонентов
