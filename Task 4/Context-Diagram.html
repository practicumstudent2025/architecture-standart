Описание диаграммы

Диаграмма контекста показывает взаимодействие системы передачи ставок с кол-центрами и внешними системами для поддержки консультаций пожилых клиентов.

Ключевые компоненты:

  • Система передачи ставок - центральный компонент, координирующий передачу данных
  • Кол-центр банка - внутренняя система с локальной базой ставок
  • Партнерский кол-центр - внешняя система, получающая данные через SFTP
  • Сервис ставок - источник данных о ставках по депозитам
  • SFTP-сервер - обеспечивает безопасную передачу файлов

Основные взаимодействия:

  • Клиенты звонят в кол-центры для консультации по депозитам
  • Сотрудники кол-центров используют системы с актуальными ставками
  • Система передачи ставок получает данные от сервиса ставок и распределяет их
  • Администратор управляет процессом передачи и мониторит систему
  • SFTP-сервер обеспечивает безопасную передачу файлов партнерскому кол-центру

Цель системы:

Обеспечить кол-центры актуальными данными о ставках для качественной консультации пожилых клиентов, которые предпочитают телефонное общение.
